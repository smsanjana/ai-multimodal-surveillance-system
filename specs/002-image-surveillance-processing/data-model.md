## 1. Domain Entities & Value Objects

### BoundingBox (Value Object)
Represents normalized or absolute bounding box pixel coordinates of a detected object.

```python
class BoundingBox(BaseModel):
    x_min: float  # Top-left X coordinate
    y_min: float  # Top-left Y coordinate
    x_max: float  # Bottom-right X coordinate
    y_max: float  # Bottom-right Y coordinate
```

---

### DetectionResult (Value Object / DTO)
Single object detection output returned by `AbstractDetectionService`.

```python
class DetectionResult(BaseModel):
    detection_id: str  # Unique UUID string
    class_id: int      # COCO / Model class identifier
    class_name: str    # Human-readable class name (e.g. "car", "person")
    confidence: float  # Confidence score between 0.0 and 1.0
    bbox: BoundingBox  # Bounding box coordinates
```

---

### FactorContribution (Value Object / DTO)
Represents a single contextual threat scoring contributor generated by `ExplainabilityService`.

```python
class FactorContribution(BaseModel):
    factor_name: str     # e.g., "Detected 3 vehicles"
    score_delta: float   # e.g., +25.0
    description: str     # Rationale description
```

---

### ThreatAssessmentResult (Value Object / DTO)
Structured threat intelligence output produced by `ThreatScoringService` and `ExplainabilityService`.

```python
class ThreatAssessmentResult(BaseModel):
    threat_score: float                  # Computed quantitative score (0.0 to 100.0)
    threat_level: str                    # LOW, MEDIUM, HIGH, CRITICAL
    factors: List[FactorContribution]    # Itemized factor attribution list
    xai_reason: str                      # Natural language justification narrative
    recommended_sop: str                 # Standard Operating Procedure action steps
```

---

### ImageAnalysisRequest (Data Transfer Object)
Input request payload sent to `ImageSurveillanceService`.

```python
class ImageAnalysisRequest(BaseModel):
    source_type: str                  # "UPLOAD" or "DEMO"
    platform: str                     # "DRONE" or "CCTV"
    scenario_name: Optional[str]      # Scenario title (for DEMO mode)
    image_bytes: Optional[bytes]      # Binary image payload (for UPLOAD mode)
    image_path: Optional[str]         # Disk path (for DEMO mode or local files)
    zone_violation_flag: bool = False # Optional pre-existing restricted zone flag
```

---

### ImageAnalysisResponse (Data Transfer Object)
Complete application processing output returned by `ImageSurveillanceService`.

```python
class ImageAnalysisResponse(BaseModel):
    analysis_id: str                          # UUID string
    timestamp: str                            # ISO-8601 string
    source_type: str                          # "UPLOAD" or "DEMO"
    platform: str                             # "DRONE" or "CCTV"
    scenario_name: Optional[str]              # Scenario name
    original_image_bytes: bytes               # Raw input image bytes
    annotated_image_bytes: bytes              # Rendered output image with bounding boxes
    detections: List[DetectionResult]         # Structured detection list
    threat_assessment: ThreatAssessmentResult # Threat intelligence & XAI
    processing_time_ms: float                 # Latency in milliseconds
    persisted: bool                           # True after SQLite save completes
```

## 2. Database Schema (SQLite)

Feature 002 reuses the existing `DatabaseService`, database configuration, schema, and database path established by Feature 001. Existing `analyses` and `detections` tables in SQLite are utilized as follows:

### Table `analyses`
| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | TEXT | PRIMARY KEY | Unique analysis UUID |
| `timestamp` | TEXT | NOT NULL | ISO-8601 timestamp string |
| `input_source` | TEXT | NOT NULL | `UPLOAD` or `DEMO` |
| `platform` | TEXT | NOT NULL | `DRONE` or `CCTV` |
| `media_type` | TEXT | NOT NULL | `IMAGE` |
| `scenario_name` | TEXT | NULLABLE | Demo scenario name if applicable |
| `threat_score` | REAL | NOT NULL | Quantitative threat score (0.0–100.0) |
| `threat_level` | TEXT | NOT NULL | `LOW`, `MEDIUM`, `HIGH`, `CRITICAL` |
| `processing_time_ms` | REAL | NOT NULL | Latency in milliseconds |
| `xai_reason` | TEXT | NOT NULL | Natural language XAI rationale |
| `recommended_sop` | TEXT | NOT NULL | Standard Operating Procedure text |

---

### Table `detections`
| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | TEXT | PRIMARY KEY | Unique detection UUID |
| `analysis_id` | TEXT | FOREIGN KEY (`analyses.id`) | Relational link to analysis run |
| `class_id` | INTEGER | NOT NULL | Object class index |
| `class_name` | TEXT | NOT NULL | Object class label (e.g. `car`) |
| `confidence` | REAL | NOT NULL | Detection confidence (0.0–1.0) |
| `x_min` | REAL | NOT NULL | Top-left X coordinate |
| `y_min` | REAL | NOT NULL | Top-left Y coordinate |
| `x_max` | REAL | NOT NULL | Bottom-right X coordinate |
| `y_max` | REAL | NOT NULL | Bottom-right Y coordinate |

## 3. State Transitions & Validation Rules

```
[ Unvalidated Image Input ]
          │
          ▼ (FR-001: ImageValidator - Validate file format & header)
[ Validated Image Frame ]
          │
          ▼ (FR-003 / FR-004: YoloDetectionService - Run YOLOv8 inference)
[ Structured Detections ]
          │
          ▼ (FR-009: ThreatScoringService - Calculate 0-100 Threat Score)
[ Threat Score & Level ]
          │
          ▼ (FR-011 / FR-012: ExplainabilityService - Build XAI & SOP)
[ Threat Assessment Result ]
          │
          ▼ (FR-005: ImageAnnotator - Render Bounding Boxes & Badges)
[ Annotated Image ]
          │
          ▼ (FR-013: AnalysisRepository - Automatic SQLite Persistence)
[ Persisted Record ]
```
